SWIM Training V10.9 — installation sur GitHub Pages

1. Ouvrir votre dépôt GitHub swim-training.
2. Choisir « Ajouter un fichier » > « Téléverser des fichiers ».
3. Décompresser l’archive ZIP, puis déposer le contenu du dossier SWIM_Training_Installable_V10_9 (index.html, manifest.webmanifest, sw.js et dossier icons) à la racine du dépôt. Attention : ne pas déposer le ZIP seul.
4. Cliquer sur « Valider les modifications ».
5. Ouvrir Paramètres > Pages et attendre la publication. L’adresse est normalement https://VOTRE_IDENTIFIANT.github.io/swim-training/
6. Sur le Samsung, ouvrir cette adresse dans Chrome > menu ⋮ > « Installer l’application » ou « Ajouter à l’écran d’accueil ».

IMPORTANT : cette version de démonstration stocke encore les données localement sur chaque appareil. La synchronisation Firebase n’est PAS activée. Les données du fichier HTML local ne migrent pas automatiquement vers le site. Exporter une sauvegarde depuis l’ancienne application avant migration.
